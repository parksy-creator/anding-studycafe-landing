# 앤딩스터디카페 랜딩페이지 (리뉴얼)

무인 스터디카페 창업 브랜드 **앤딩스터디카페**의 창업 상담용 랜딩페이지입니다.
빌드 도구 없이 HTML/CSS 한 파일로 되어 있어, 파일을 열면 바로 확인할 수 있습니다.

## 리뉴얼 배경

기존 페이지(andingstudy.com)는 전체가 이미지 72장으로 제작되어 있었습니다.

| 항목 | 기존 | 리뉴얼 |
|---|---|---|
| 구성 | 이미지 72장 | HTML 텍스트 |
| 검색엔진이 읽는 글자 | 183자 | 전체 색인 가능 |
| 이미지 alt | 없음 | 해당 없음 (텍스트) |
| 모바일 확대 | 차단(`user-scalable=no`) | 정상 |
| 모바일 메뉴 | 없음 | 햄버거 메뉴 |
| 문구 수정 | 디자인 재발주 필요 | 텍스트만 수정 |

기존 페이지의 매출·손익·비교 데이터는 **모두 그대로 옮겼습니다.**

## 페이지 구성

1. 히어로 — 42개 매장 / 폐점 0%
2. 지표 — 42개 · 폐점 0% · 회수 18.7개월 · 시간당 1,000원
3. THE RESULT — 지점 3곳 실제 매출 (2025년 6월 기준)
4. PROFIT & LOSS — G·Y지점 손익 (2025년 1~8월)
5. COMPARE — 40평 기준 타사 비교
6. 전환 밴드 — "3년 뒤에도 열려 있느냐"
7. THE PROBLEM — 창업 전 착각 3가지
8. THE GUIDE — 직영 선(先) 검증 원칙
9. THE SYSTEM — 자체 개발 무인 시스템 + AI 학습관리 무료
10. 편의 12종 — 재방문 요인
11. THE PLAN — 창업 절차 5단계
12. FAQ / 상담 신청 / 하단 고정 상담바
